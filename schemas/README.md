# Schemas oficiais

Arquivos XSD originais, sem edição/reformatação. Proveniência, hashes por arquivo/ZIP e revisão: `manifest.json`. Escopo e composição do pacote incremental 010f com raiz de processo 009k: [documentação](../docs/xml-validation.md).

Verificação: `npm run schemas:check`. Não remover dependências `xs:include/import`. Não baixar URLs indicadas por XMLs dos usuários. Atualizações exigem revisão, novos testes e migration de versão; não são automáticas.
